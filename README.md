Features
Hiro marker scene: plane (floor), spheres (glass orb, core, star), tori (glowing rings), rings/circles (swirling purple vortex arms), boxes (spark streaks), 3D model, <a-text> labels.
Animation: the truck orbits (rotation) and the star bounces (position).
3D model: Cesium Milk Truck (glTF/GLB).
Interaction: tap the star to change colour (color-changer); tap the glowing orb to grow the whole vortex and reveal a warning (void-grow, my own component); the vortex itself is built by my void-build component.
Status banner: red/green text for marker lost/found
